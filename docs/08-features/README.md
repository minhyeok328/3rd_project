# 기능 명세

[문서 목록](../README.md)

## 직접 검색

- 입력: 식당이름·메뉴·유저명 중 선택한 항목과 문자열
- 처리: `add_search`가 세 슬롯을 구성하고 `db_fixed_search` 호출
- 결과: 매칭 엔티티와 연결된 식당 카드·좌표
- 예외: 필수 키 누락·조회 실패·매칭 없음은 빈 결과로 보일 수 있음
- 확인: 여러 메뉴가 같은 식당을 가리킬 때 중복과 상세 연결 점검

## 자연어 추천

- 입력: 음식·분위기·식당에 관한 질문
- 처리: 라우팅 → 슬롯 → 검색 → 후보 재정렬 → 생성
- 결과: 스트리밍 답변과 생성기에 사용한 후보
- 예외: 모델 호출 실패·잘못된 JSON은 처리 중 오류로 전파될 수 있음
- 확인: 추천된 식당·메뉴·인용 리뷰가 후보에 실제로 있는지 대조

## 식당 상세

- 입력: 목록 카드 선택
- 결과: 주소, 수집된 영업시간, 메뉴 가격, 리뷰와 태그
- 상태: 선택된 식당을 `st.session_state`에 보관, 닫기 시 목록 복귀
- 확인: 결측값·숫자가 아닌 가격·좌표 누락과 긴 리뷰 표시

## 지도

- 입력: 후보/상세 식당 좌표와 지도 JavaScript 키
- 결과: 마커와 후보 중심 또는 선택 식당 중심
- 예외: 키가 없으면 지도 설정 안내 표시
- 확인: 카드와 마커 대상 일치, 외부 SDK 로드 실패와 좌표 유효성

## 대화 상태

- 화면 메시지와 모델 이력은 별도로 관리합니다.
- 웹에서 고정 대화 ID를 사용하므로 다중 사용자 격리는 지원하지 않습니다.
- 모델 이력에 만료·길이 제한이 없어 장시간 대화 시 문맥이 계속 커질 수 있습니다.

기능의 구현 위치는 [프런트엔드](../03-frontend/README.md)와 [백엔드](../04-backend/README.md), 확인 방법은 [검증 문서](../10-quality/verification-and-limitations.md)에 연결됩니다.
