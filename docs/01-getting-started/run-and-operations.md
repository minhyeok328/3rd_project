# 실행과 운영

[문서 목록](../README.md)

## 시작 전 확인

[개발 환경](development-environment.md)의 패키지·키·DB 준비를 완료한 뒤 프로젝트 루트에서 실행합니다. DB가 없는 상태에서 앱을 실행하면 SQLite가 빈 파일을 만들고 조회 오류가 빈 검색 결과로 보일 수 있습니다.

```powershell
Test-Path database/sql/restaurant.db
python -m pip check
```

첫 명령의 결과가 `False`이면 DB 준비를 먼저 완료합니다.

## Streamlit 실행

```powershell
python -m streamlit run main.py
```

터미널에 출력된 로컬 URL로 접속합니다. 기본 포트는 8501이며 실제 적용 주소는 실행 로그를 따릅니다. 종료는 터미널에서 `Ctrl+C`를 누릅니다.

`experiments/frontend/app.py`는 `import utils` 및 현재 검색 함수와 맞지 않는 호출이 있는 초기 실험 파일이므로 대체 실행 경로로 안내하지 않습니다.

## CLI 실행

```powershell
python -m src.pipeline
```

질문을 입력하면 파이프라인 결과를 출력합니다. 빈 입력·EOF·인터럽트로 종료합니다. CLI와 웹 채팅 모두 실제 모델 호출 비용이 발생할 수 있습니다.

## 기본 확인 절차

1. 직접 검색에서 준비된 DB에 존재하는 식당명을 검색합니다.
2. 카드의 상세 메뉴·리뷰·좌표가 같은 식당을 가리키는지 확인합니다.
3. 자연어 질문을 보내 답변과 후보 목록을 함께 확인합니다.
4. 지도 키가 없을 때 안내가 보이고, 키가 있을 때 좌표가 표시되는지 확인합니다.
5. 검색 결과가 없는 입력과 외부 API 실패 시 동작을 확인합니다.

## 문제 해결

| 현상 | 확인할 사항 |
| --- | --- |
| 시작 전 OpenAI 키 오류 | import 시 클라이언트를 만드는 검색 유틸과 `OPENAI_API_KEY` |
| 검색 결과가 계속 비어 있음 | DB 경로·파일 크기·테이블 존재 여부. `query_sender`가 SQL 예외를 빈 DataFrame으로 바꿈 |
| 임베딩 계산 오류 | 저장 벡터의 base64/float32 형식과 차원, API 접근 상태 |
| 지도 미표시 | `KAKAO_MAP_KEY`, 실행 웹 도메인, 좌표·브라우저 네트워크 |
| 상세 화면 데이터 오류 | 메뉴 가격·좌표·리뷰 컬럼과 결측값 |
| 과거 대화가 섞임 | 고정 `test_session`과 프로세스 전역 대화 저장소 사용 여부 |

## 데이터 교체와 상태

DB를 교체하기 전 실행을 종료하고 기존 파일을 별도 보관합니다. CSV와 임베딩 모델·차원·관계 코드의 정합성을 확인한 후 다시 시작합니다. 자동 마이그레이션·재시도·백업·복구 도구는 없습니다.

화면 상태는 `st.session_state`, 모델 대화 이력은 `src/generator.py`의 메모리에 있습니다. 재시작하면 메모리 이력이 사라지며, 화면 새로고침만으로 전역 모델 이력이 반드시 지워지는 것은 아닙니다.
