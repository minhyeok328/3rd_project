# 배포와 운영 조건

[문서 목록](../README.md)

## 저장소에서 제공하는 범위

Streamlit 실행 소스와 Python 의존성이 있습니다. Dockerfile·Compose·CI 배포·리버스 프록시·운영 도메인 설정은 포함되어 있지 않습니다. 기본 실행 방법은 [실행과 운영](../01-getting-started/run-and-operations.md)을 따릅니다.

## 실행 환경에 필요한 자료

| 항목 | 준비 내용 |
| --- | --- |
| Python | requirements와 호환되는 가상환경, 실제 설치 버전 기록 |
| 데이터 | 식당 DB, 임베딩·관계 무결성 확인, 백업 사본 |
| 모델 연결 | OpenAI 키, 호출 가능한 모델, 네트워크 |
| 지도 | JavaScript 키와 배포 주소 설정 |
| 정적 파일 | prompts와 img 디렉터리 포함 |
| 프로세스 | Streamlit 서비스의 시작·종료·로그 보관 방식 |

## 공개 운영 전 해결할 제약

- `main.py`의 고정 `test_session`과 전역 모델 이력 때문에 사용자 간 대화가 섞일 수 있습니다. 고유 세션 ID·이력 만료·삭제가 필요합니다.
- 인증·요청 제한·모델 비용 제한·공통 오류 응답은 없습니다.
- HTML을 조립하는 화면과 지도 데이터 삽입은 신뢰할 수 없는 데이터에 대한 검토가 필요합니다.
- DB 쿼리 실패가 빈 결과로 감춰질 수 있어 장애 관찰과 정상적인 검색 없음의 구분이 필요합니다.
- 여러 프로세스를 띄우면 메모리 대화 이력이 서로 공유되지 않습니다.
- 수집 데이터의 갱신·이용 범위와 외부 이미지 의존성을 확인해야 합니다.

이 문서는 운영 환경이 이미 구축됐다는 의미가 아닙니다. 현재 구현은 준비된 데이터를 사용하는 로컬 데모의 실행 구성을 설명합니다.

## 복구 기준

모델 실패는 DB 재생성으로 해결하지 않습니다. 키·네트워크·모델 응답을 먼저 확인합니다. DB 문제가 확인되면 앱을 종료하고 검증한 백업을 복원한 뒤 직접 검색→추천→지도 순서로 점검합니다. 재시작 시 메모리 대화 이력은 보존되지 않습니다.
