# 수집 원본

식당 검색 페이지와 개별 식당 HTML, 링크 목록, 파싱·수집 스크립트를 보관합니다.

| 파일·경로 | 용도 |
| --- | --- |
| `page_search.txt` | 저장한 검색 결과 HTML |
| `page_sample.txt` | 상세 페이지 샘플 |
| `link_restaurants.txt` | 추출한 식당 링크 |
| `0_page_search_parser.py` | 검색 결과에서 식당 링크 추출 |
| `1_dynamic_crawling.ipynb` | 동적 페이지 수집 실험 |
| `restaurants/` | 개별 식당 HTML |

수집 자료는 당시의 스냅샷입니다. 자동 갱신이나 현재 영업 정보 검증을 제공하지 않습니다. 노트북 재실행 전 저장 경로·선택자·외부 서비스 이용 조건을 확인합니다.
